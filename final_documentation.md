# Ответственный: Амирзянова Камила

Начнем с работы над API. Были рассмотрены 3 самых известных API по поиску билетов: Travelpayouts, Kiwi Tequila и Amadeus. Поскольку первые два являются закрытыми и недоступными для некоммерческого проекта, использовали бесплатную версию API Amadeus. Она ограничена в тестах и количестве запросов, но этого более, чем достаточно, для нашего проекта. 
TL зарегистрировался и получил API код и секрет, которые были внесены в отдельный конфигурационный файл. 

В папке services был реализован client.py. В этом файле было установлено управление HTTP-сессиями через requests.Session() для оптимизации производительности, прописана функция по управлению токенами и построена JSON-структура, пример которой был представлен на официальном сайте API Amadeus для корректного ввода запроса. Также реализован parser для извлечения данных из ответов API в формате JSON, который также был представлен на официальном сайте. 

Далее была проведена работа с базами данных. Для хранения данных используется библиотека sqlalchemy и aiosqlite. Для одновременной работы с множеством пользователей используется асинхронный подход

# Ответственный: Леденева Дарья

Теперь подробнее к основной логике бота. Точкой входа является файл main.py. Использует asyncio для асинхронного запуска. Инициализирует БД, подключает обработчики и запускает поллинг бота

config.py – содержит настройки проекта. Использует dotenv для загрузки переменных окружения. Хранит токены, API-ключи и параметры подключения к БД

loader.py – инициализирует основные объекты: бот (aiogram), диспетчер и клиент Amadeus API.

states.py – определяет состояния конечного автомата (aiogram.fsm) для управления диалогами: поиск рейсов и проверка бронирования

iata.py – содержит словарь для преобразования названий городов/аэропортов в IATA-коды. Используется для нормализации пользовательского ввода

keyboards.py – предоставляет функции для создания клавиатур (aiogram.types). Используется для главного меню, управления избранным и навигации

Обработчики (handlers):

common.py – базовые команды бота. Использует aiogram для обработки команд и кнопок

search.py – пошаговый поиск авиабилетов через Amadeus API с использованием FSM. Интегрирует IATA-модуль и API-клиент

favorites.py – управление избранными билетами. Взаимодействует с БД через асинхронные запросы

booking.py – проверка бронирования. Определяет авиакомпанию по коду и предоставляет ссылку на сайт
